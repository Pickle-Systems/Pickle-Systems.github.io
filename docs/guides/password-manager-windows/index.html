Windows password managers and TOTP: what to know

A password manager can make unique passwords easier to manage. This guide explains the basics, how time-based one-time passwords work, and what to review before choosing a Windows password manager.

Why use a password manager?

Reusing one password across multiple websites creates a chain reaction risk: if one service is breached, attackers may try the same password elsewhere. A password manager helps you keep a different password for each account without having to memorize every one.

Instead of remembering dozens of credentials, you protect access to a dedicated app or vault and use it to organize your account information. The security of that setup depends on the app's design, how it stores data, and how you protect your device and backups.

What makes a strong password?

  • Use unique passwords: Never reuse an important password across multiple services.
  • Prefer length: Longer passwords or passphrases are generally harder to guess.
  • Avoid personal details: Names, birthdays, and predictable patterns can be easy to guess.
  • Use a password generator: Randomly generated passwords avoid common words and patterns.
A password manager is only one part of account security. Keep your operating system updated, protect your device login, and make sure you have a safe recovery plan.

What is TOTP two-factor authentication?

TOTP stands for time-based one-time password. It is a type of authenticator code that changes at regular intervals, commonly every 30 seconds. A service and an authenticator app use a shared secret and the current time to independently calculate the same short code.

When signing in, you enter your password and then provide the current authenticator code. This adds a second step beyond the password alone. TOTP is useful, but phishing-resistant passkeys or hardware security keys can provide stronger protection where supported.

What should you check in a Windows password manager?

  1. Storage and encryption: Look for clear documentation explaining how credentials are protected at rest and what encryption is used.
  2. Recovery and backups: Understand how to back up your vault and what happens if you lose access to the app or device.
  3. Offline behavior: Check whether the app requires an account or cloud connection, and whether it sends data to external services.
  4. Authentication features: Decide whether you need TOTP support, passkey support, or integration with external authenticators.
  5. Platform support: Verify Windows version, 32-bit or 64-bit requirements, installation method, and update process.
  6. Project transparency: Review release history, documentation, source availability, and security reporting.

Frequently asked questions

Is a password manager safer than reusing passwords?

Using unique passwords reduces the risk that one breached account exposes other accounts. A password manager can make unique passwords practical to maintain, but its own security and your device security still matter.

Is TOTP the same as SMS verification?

No. TOTP codes are generated by an authenticator using a shared secret and time. SMS codes are delivered through the mobile network and have different security risks.

Can I use a password manager offline?

Some password managers support local or offline use, while others rely on cloud accounts or synchronization. Check the specific product's documentation and behavior.
